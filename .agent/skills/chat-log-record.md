# Skill: 對話紀錄

## 目的

維護使用者與 agent 的 Markdown 對話摘要，讓作業要求的 GPT 輔助內容能被匯出或整理進最終報告。
當使用者提出需求、要求實作、接受決策，或 agent 提供有意義協助時，必須使用此 skill。

## 紀錄檔案

更新：

```text
.agent/records/CHAT_LOG.md
```

## 必要行為

1. 對有意義的互動追加含日期時間的紀錄。
2. 同時摘要使用者需求與 agent 回覆或完成的工作。
3. 清楚標示可作為 GPT 輔助內容的部分。
4. 紀錄要精簡，但需具體到足以支援最終 PDF 匯出要求。
5. 不要寫入密碼、token、私人憑證或不必要的個資。
6. 所有 `.agent/records` 內的紀錄一律使用繁體中文；專有名詞、程式檔名、資料集名稱、指標縮寫與原始英文標題可保留英文。
7. `.agent/records/CHAT_LOG.md` 必須依時間由舊到新排列；新增紀錄後若同檔已有較晚時間的紀錄，需插入正確位置或重新排序。
8. 若多筆紀錄時間精確到同一分鐘，保留原本相對順序，或在必要時補上更精確的時間以避免混淆。

## 紀錄模板

```markdown
## YYYY-MM-DD HH:MM

### 使用者需求

- ...

### Agent 回覆與完成工作

- ...

### GPT 輔助內容標記

- 是否放入報告：是/否
- 建議標籤：GPT 輔助內容
```

## 最終必要用途

最終報告必須清楚包含或引用：

- 透過 pdfCrowd 或其他工具匯出的 GPT 對話 PDF。
- 標示為 `GPT 輔助內容` 的章節。
- GPT 協助過的作業部分，例如資料集規劃、程式產生、CRISP-DM 撰寫、特徵選擇、視覺化與報告潤飾。

## 品質標準

紀錄應能讓讀者不需要完整原始對話，也能重建 GPT 協助了哪些內容。
