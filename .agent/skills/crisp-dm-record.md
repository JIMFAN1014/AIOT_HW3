# Skill: CRISP-DM 紀錄

## 目的

維護可直接整理進報告的 CRISP-DM 筆記，用於 HW3 多元線性回歸分析。
當分析內容、程式碼、圖表、模型結果或報告文字變更時，必須使用此 skill。

## 紀錄檔案

更新：

```text
.agent/records/CRISP_DM.md
```

## CRISP-DM 階段

每個階段都必須有紀錄：

1. Business Understanding
2. Data Understanding
3. Data Preparation
4. Modeling
5. Evaluation
6. Deployment

## 必要行為

1. 編輯分析程式或報告文字前，先讀取 `.agent/records/CRISP_DM.md`。
2. 完成有意義的工作後，更新對應的 CRISP-DM 階段。
3. 筆記要用可重用於最終報告的語氣撰寫。
4. 紀錄實際證據，不只寫計畫：
   - 資料集列數與欄數。
   - 特徵名稱與目標變數。
   - 缺失值處理。
   - 編碼與標準化決策。
   - 特徵選擇方法與已選特徵。
   - 模型類型。
   - 評估指標。
   - 預測圖與區間方法。
5. 未完成項目標記為 `TODO`，方便搜尋。
6. 所有 `.agent/records` 內的紀錄一律使用繁體中文；專有名詞、程式檔名、資料集名稱、指標縮寫與原始英文標題可保留英文。

## 必要報告證據

紀錄最終必須包含：

- 資料集來源與 Kaggle 連結。
- 研究脈絡，以及為什麼該預測目標有意義。
- 資料清理與準備步驟。
- 特徵選擇方法。
- 線性回歸建模流程。
- 適用時包含 MAE、MSE、RMSE、R2 等指標。
- 預測視覺化規劃與產生的圖片路徑。
- 信賴區間或預測區間說明。
- 與網路主流或更佳解法的比較。
- Deployment 與繳交說明。

## 品質標準

紀錄應接近最終報告文字，能夠被複製、潤飾並放入 PDF 報告。
