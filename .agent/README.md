# Agent Working Rules for HW3

This directory stores the project-specific rules and living records for this homework.
All future development in this repository must follow the skills in `.agent/skills`.

## Required Skills

Before making any meaningful change, the agent must read and follow:

1. `.agent/skills/spec-record.md`
2. `.agent/skills/crisp-dm-record.md`
3. `.agent/skills/chat-log-record.md`

## Living Records

The skills write project memory into Markdown files under `.agent/records`:

- `.agent/records/SPEC.md`: assignment requirements, dataset choice, deliverables, and decisions.
- `.agent/records/CRISP_DM.md`: CRISP-DM progress and report-ready notes.
- `.agent/records/CHAT_LOG.md`: summary of user-agent conversations and GPT-assisted content.

## Development Policy

- Keep all records in Markdown.
- Update the relevant record whenever a requirement, decision, dataset, model, result, or report content changes.
- Do not rely on memory alone. If it matters for grading or reproducibility, write it down.
- Keep the homework aligned with the official HW3 requirements:
  - Kaggle public dataset with about 10 to 20 features.
  - Linear Regression / Multiple Linear Regression.
  - Feature Selection.
  - Model Evaluation.
  - Prediction plot with confidence interval or prediction interval.
  - Full CRISP-DM explanation.
  - GPT-assisted content clearly marked.
  - NotebookLM summary of at least 100 Chinese words.
  - Final zip named by student ID.
